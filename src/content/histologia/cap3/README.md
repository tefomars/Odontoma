# Capítulo 3 — Núcleo celular

Fuente: Ross y Pawlina, *Histology: A Text and Atlas*, 8.ª edición,
capítulo 3, pp. 82–105, en `rossenglish.txt` aportado por el usuario.
Se leyó el desarrollo completo, incluidos los recuadros y el resumen.

268 flashcards en siete bloques y 18 subtemas. Banco independiente de
100 preguntas de opción múltiple, con alternativas personalizadas y explicación
fuera de las opciones. Ambos se integran en Fundamentos y en la biblioteca del
builder sin modificar bancos previos ni progreso del estudiante.

## Cobertura

- Cromatina, nucleosomas, heterocromatina, X inactivo, cariotipo y telómeros.
- Nucléolo: regiones, ARNr, procesamiento y ensamblaje ribosómico.
- Envoltura, lámina, poros, importación y exportación.
- Renovación, quiescencia, fases, controles y ciclinas–Cdk.
- Mitosis: cinetocoros, cohesinas, huso y citocinesis.
- Meiosis: profase I, recombinación, segregación y cantidad de ADN.
- Muerte celular: morfología, apoptosis, anoikis y otras respuestas reguladas.

## Criterios

Se usa n para juegos cromosómicos y C para cantidad de ADN (el libro usa d para
esta última). Se evita confundir 2n/4C con tetraploidía, homólogos con hermanas
o centrómero con cinetocoro. No se presenta la fibra de 30 nm como estructura
universal obligatoria, ni se reproduce el umbral OCR de «9 Da» del poro.
Se distingue apoptosis fisiológica y patológica; autofagia no equivale por sí
sola a muerte y catástrofe mitótica no se enseña como una vía ejecutora única.
Se omiten cifras históricas del genoma y afirmaciones clínicas o terapéuticas
que no son necesarias para el objetivo histológico del capítulo.
